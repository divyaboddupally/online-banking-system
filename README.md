# Online Banking System - MERN College Project

## Requirements
- Node.js
- MongoDB (local or Atlas)

## Run backend
cd backend
copy .env.example .env   (Windows)
npm install
npm run dev

## Run frontend
cd frontend
npm install
npm run dev

Open the Vite URL shown in the terminal.

This is a college-level banking simulation. It includes basic registration/login/logout and banking operations, but it is not intended for real banking or production use.
